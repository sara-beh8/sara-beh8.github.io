# sara-beh8.github.io

Source of my portfolio: **[sara-beh8.github.io](https://sara-beh8.github.io)**. It has growth marketing case studies from 2015 to today, with the story behind every number.

**What's inside:** demand generation (live product-demand tests), lifecycle systems (a campaign program that renews itself), data & measurement (honest, human-only metrics) and AI automation (an outbound research engine).

**How it's built:** one hand-written `index.html` with inline CSS and a little vanilla JS. There's no framework and no build step, and it's served by GitHub Pages.

The systems behind the case studies are documented, generalized, in
[lifecycle-campaign-skills](https://github.com/sara-beh8/lifecycle-campaign-skills),
[lifecycle-ops-standards](https://github.com/sara-beh8/lifecycle-ops-standards) and
[growth-dashboard-spec](https://github.com/sara-beh8/growth-dashboard-spec).
